The `host_git_commit` in `run-context.txt` is the **base commit before the
hardware evidence commit**. The evidence and design files were committed
immediately afterwards; use `git log -- hardware/prototype-v1` to find the
corresponding commit. Re-running the script updates `run-context.txt` and all
reports.

The reports are deliberately not edited. Do not quote a clean count from a
different KiCad version or rule set. The DRC after zone re-fill uses the
upstream `v0.4.4d.kicad_pro` board settings; the pre-refill run reported 766
violations. Both numbers are explained in `AUDIT/PCB_CHECK_RESULTS.md`.
